# Firebase: подключение push (FCM)

Firebase нужен только как транспорт: FCM бесплатен на любом тарифе, карта не нужна, аналитика выключена
(`AndroidManifest.xml`). Содержимое уведомлений зашифровано ключом телефона — Google его не видит
(`ANDROID_CONTRACT.md` §5).

## 1. Проект
1. <https://console.firebase.google.com> → «Создать проект» → название `AshCRM`. Google Analytics — **не включать**.
2. «Добавить приложение» → Android:
   * пакет `ru.ashcrm.app`, название «AshCRM». SHA-1 не нужен (он для входа через Google, не для push).
3. Ещё раз «Добавить приложение» → Android → пакет **`ru.ashcrm.app.debug`** (отладочная сборка ставится рядом с
   боевой и тоже должна получать push).
4. «Настройки проекта» → «Общие» → скачать `google-services.json` (в нём оба пакета).

## 2. Приложение
Положить файл в `app/google-services.json` (в git не попадает, `.gitignore`) и собрать заново. Сборка сама включит
FCM (`BuildConfig.HAS_FIREBASE`); без файла приложение собирается и работает без push — на экране настроек это
видно: «Эта сборка без Firebase».

`google-services.json` не секрет в строгом смысле (он внутри каждого APK), но хранить его стоит рядом с ключом
подписи — без него новые сборки не получат push.

## 3. Сервер CRM
1. «Настройки проекта» → «Сервисные аккаунты» → «Создать закрытый ключ» → JSON.
2. Это **секрет**: файл даёт право слать push всем установкам. Положить на сервер CRM вне git и образа, права `600`,
   путь — в `ASH_FCM_CREDENTIALS` (RUNBOOK CRM, раздел «Приложение для Android»).
3. «Настройки проекта» → «Cloud Messaging»: «Firebase Cloud Messaging API (V1)» должен быть «Включён»
   (у новых проектов так по умолчанию). «Legacy API» не нужен.

## 4. Проверка
Приложение → долгое нажатие на иконку → «Настройки уведомлений» → «Проверить» → «Уведомление пришло».
